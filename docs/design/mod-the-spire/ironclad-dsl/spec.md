# 铁甲战士完整卡牌与共享接口

关联 **CORE-AUTHOR-05／DSL-IRONCLAD-ALL-01**；用户于 2026-10-18 明确优先完整铁甲战士。当前状态、认领与下一机制唯一维护在[GitHub 任务清单](https://github.com/QingXiang22/auto-the-spire/issues/28)。沿用[纯 DSL 边界](../base-architecture.md)，旧 C# 卡牌实现仅作迁移验证记录。

## 范围与来源

以 `IroncladCardPool.GenerateAllCards()` 和 `tools/base-spire-dev/fixtures/source-catalogs.json` 中 cards 域的完整 87 项铁甲战士源标识为准，单人适用 85 项；DemonicShield／Tank 的源 MultiplayerOnly 保留，不计单人运行支持。原全卡目录 578 项、池成员和顺序不缩减。已有 29 张铁甲战士定义继续核对并复用，其余按依赖补齐。所需生成牌与 Power 也必须有真实行为；未支持的池成员明确失败，不能从生成池删掉它们。

玩法只在 `.spire`；具体内容文件仅用模板配置。共享过程按卡牌、战斗、能力归属，Host 不解释卡牌 ID／效果字符串。分别报告源 hash、实际定义、普通／升级行为、独立比较和公开可用的验证结果；只声明 Power 名称不算支持。

## 共享约定

| 能力 | 输入、状态与顺序 | 关键判别 |
| --- | --- | --- |
| 显式目标 | 实际手牌 card，存活敌人候选；可由通用 Engine 决策选择 target，选定后才支付和打出 | 选择非首个敌人；非法／过期应答无副作用；合法候选与支付条件一致 |
| 单张选牌 | 依调用方从 Hand／Discard／RunDeck 等构造真实资格；Engine 固定候选并续接；要求选择或允许取消明确区分 | 空域不暂停；来源牌已经 InPlay，不能误选正在打出的牌；暂停不重复支付／前置效果 |
| 完整消耗 | 从当前战斗牌区移出，放入 ExhaustPile，再发 CardExhausted；已消耗对象不得重复发 | DarkEmbrace／FeelNoPain、DrumOfBattle 的监听；快照遍历不吞新抽牌、不重复处理 |
| X 与费用 | 付款前捕获本次 PaidX，费用与本回合覆盖可公开查询；保留原始／升级费用和失效边界 | 0／多点 X、免费出牌、临时减费与次回合恢复、升级和实例隔离 |
| 类型／标签／历史 | 使用实际源 CardType 和 Strike tag；每次真实出牌有独立记录，不用唯一实例集合模拟次数 | 同实例重复出牌、当前牌计入何种开始／完成历史、回合／战斗重置 |
| 结算收尾 | 支付→Hand 到 InPlay→每次前置／效果／finished 历史／后置→全部重复完成后移到结果牌区或消耗→最终胜负／奖励；依据源 CardModel.OnPlayWrapper，嵌套不提前终止父过程 | Feed 致命后的最大生命、最后一击后抽牌／选牌、所有命中与消耗监听完成；死亡玩家不能判胜 |
| 随机目标／牌选择 | 每次从实际资格列表抽样，空域不消费 RNG；开发命名流与源 run 流差异明确保留 | 固定 seed 重复、目标死亡后重建下一击资格、不缩池伪造结果 |
| 能力反应 | 按源精确绑定获得格挡、生命损失、消耗、回合、伤害修正与抽牌事件，保留参与者、寿命和源顺序 | 数量／多实例／零域；非来源事件不触发；死亡、移除、临时和永久边界 |
| 自动／重复出牌 | 共用出牌过程，显式付款模式、目标策略、强制消耗和结果区；保留嵌套父上下文与实际次数 | Havoc／Cascade、OneTwoPunch、Hellraiser／Stampede，禁止通过再次收费或手写 C# 调度替代 |

这些是完整实施约定，尚未交付能力保持未支持，不能把表格当作已实现声明。单人范围不自动授权多人或暂停的敌人召唤／复活。准确过程签名、定义自动注册、费用寿命、事件和未支持边界见[共享操作参考](shared-operations.md)。

X 牌按源 CardEnergyCost.GetAmountToSpend 首先支付当前能量，普通免费修正不能改变它；自动出牌只捕获、不支付。InfernalBlade 的免费修改在打出或回合结束时失效，Stomp 的本回合加性减费独立保留。HowlFromBeyond 没有原生 Exhaust，只有耗尽堆中的回合末自动打出，不能从 hover tip 推导关键词。BodySlam 的计算伤害仍走 powered 修正链。

## 验证与交付

### 不可打出负费用与在手回合末效果

锁定来源的Infection将CanonicalEnergyCost保留为-1，并带Unplayable。Card.Cost／BaseCost及定义、获得和复制入口允许-1；局部费用计算在基础费用为负时直接保留哨兵，不让set／add／免费修改将其变成0。普通和X费用沿用各自语义。不可手动出牌仍由关键词资格拒绝，不能因为负费用通过能量比较而获得候选或增加能量。自动尝试走AutoPlayCmd的Unplayable分支：移入打出区再进结果牌区，不付款、不执行正文、不写真实出牌历史；这与手动拒绝后的原子性不同。

回合末先保存原手牌的效果牌与其余虚无牌名单。虚无牌先耗尽，再按原手牌顺序逐张将效果牌移到InPlay、执行CardTurnEndInHandEffect、按当时虚无资格耗尽或放入弃牌堆底部。随后才做普通手牌清理；中途新抽入的牌不进入本次效果快照。效果牌即使保留也要离开手牌；移动不发主动弃牌通知，不计出牌次数。死亡后仍调用已选效果牌的回调，但后续牌区命令拒绝移动：致死牌留在InPlay，尚未处理的效果牌留在手牌。后续伤害无效，不再清理普通手牌、运行敌方行动或发后续回合通知。

Infection在该效果站点对持有者造成3点可格挡、无加成Move伤害，保留自身牌源及空CardPlay。伤害仍经共享DamageResult与生命损失／失败通知，不能用绕过格挡的LosePlayerHp替代；Strength／Weak／Vulnerable等攻击修正不参与。非手牌实例不触发；不可升级、复制保留负费用与关键词，跨战由既有卡牌清理处理。双侧比较与公开轨迹分别验证这组组件，不代表父事件或完整Run。

每个纳入运行支持的内容必须实际执行普通／升级及独有生命周期。纯数值同族采用表驱动，机制用代表边界；不逐卡复制全部引擎套件。固定本地 seed 20261018，随机机制加 777 对照；原版 RNG 不一致时不将开发确定性算作独立参考比较。

公开接口以同一 DSL 的 describe／catalog／start／step／observe 验证。选牌／选目标先复用 `net.answer_decision`；没有业务必要不扩展 wire。保留完整池和未实现清单，最终核对 85 项单人范围。完整 Run、正常奖励来源、原版独立比较与 ENV/W 父项不因本包局部通过而关闭。
