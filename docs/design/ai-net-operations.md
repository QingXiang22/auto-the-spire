## 1. 部署形态与配置

E0 只有本地 Python 编码库和样例；E1 为 Python 客户端启动 .NET stdio 环境 worker；E2 增加离线 learner/evaluator 与本地模型包；真实部署使用同样的客户端与模型接口，游戏连接由真实适配器拥有。训练和部署可使用不同框架/设备，但模型、目录与数值兼容要验证。

RuntimeProfile 记录：后端 identity、场景、产物目录、帧/实体/字段/候选上限、会话/请求账本容量、step/observe 截止时间、worker 数、CPU 线程、推理精度、模型路径与摘要、ExecutorProfile、数据保留/磁盘限制。必需限额未配置则不得启用无人值守控制；fixture 编码可以用明确有限的小规模配置。

每个 worker 使用独立会话/RNG/状态，不共享可变游戏状态。stdout 仅协议，日志 stderr；训练进程退出要释放自己启动的环境进程。真实外部游戏不是客户端拥有的子进程，close 不默认杀游戏或删除存档。启动日志不得带完整隐藏状态；内部诊断和公开训练数据分目录、分访问路径。

## 2. 指标与资源门槛

| 指标 | 度量与处理 |
| --- | --- |
| 决策延迟 | 分投影/传输/编码/推理/选择/结算记录，报告 P50/P95/P99 和最大值；预算在目标 CPU 上批准 |
| 规模 | net 按 entities/entity_fields/relations/piles/visible_members/known_positions/sequences/elements/groups/members/legal_actions/action_fields 和帧字节计数，limits 精确键见契约资产；AI 另报张量块及 batch padding，超限报错不截断 |
| 模型成本 | 所有 embedding 与层参数、权重文件字节、加载耗时、推理峰值内存；量化后重新测 |
| 正确性 | stale/非法输入/非法概率/unknown 执行/后端故障次数与比例；任一实际错误执行须阻止该配置继续发布 |
| 训练进度 | 实际环境决策数、任务完成数、中断、采样/更新吞吐及学习曲线；数据排除原因可查 |
| 存储 | 轨迹/checkpoint/请求账本容量与剩余空间；测单步公开快照典型/极端字节、快照去重率、每局与计划决策总量估算，不臆造固定数值；接近上限停止采样或淘汰可删产物 |

原始 ID/request_id 可进入诊断日志但不当模型特征；seed 是评估元数据，公开结果与内部诊断不混合。阈值没有批准时仅报告观察值，不写 SLO 达标。首版没有网络服务可用性承诺，不套用远程服务百分比目标。

## 3. 停止、故障和恢复

结构错配、候选空而未终止、无效概率、模型包不兼容、所需公开结构缺失或资源超限：在执行前停止，保存公开输入与分类错误。不要自动随机出牌、补历史或读取隐藏值继续。stale 仅重新 observe/predict，不提交旧概率。

如果动作等待超时或连接断开，执行器查询原 request_id，并按返回状态处理：

- 已完成：接收原结果。
- pending：按配置继续等待。
- unknown，或提供方崩溃且无法证明结果：停止控制。

活跃进程能够安全去重，不代表真实点击跨崩溃后可以重复。参见[生命周期](net-the-spire/protocol.md#5-生命周期与恢复)。

模拟 worker 故障：记录基础设施中断，隔离未完成转移，关闭失效会话，必要时启动新 worker 和新局。学习 checkpoint 可恢复训练进度，但不默认恢复游戏中途。真实后端故障：先核对当前局及动作结果，能力不足则由维护者处理；禁止自动存读档或回到之前结果。

用户停止：不发新玩家动作，不撤销已经开始的动作；等待/查询完成或记录 uncertain，保存中断原因并释放外部控制。技术中断和用户停止不定义输赢奖励。

## 4. 产物、保留与发布

目录/Manifest/配置和评估摘要版本化；轨迹和 checkpoint 在运行指定的产物根下管理。每次运行使用独立 run_id；保存文件使用临时文件写完后替换并校验摘要，避免部分 checkpoint 被加载。自动淘汰仅作用于该运行明确拥有且按保留策略可删的产物，不删除源码、他人文件或唯一有效恢复点。

保留策略由 CapacityProfile 给出：最新有效恢复点、已发布模型及其评估证据必须保留；原始轨迹上限/保留周期按成本与可复核性决定，删除前留下来源摘要及排除原因。训练 rollout 缓存与长期分析归档分开，算法不用旧数据不代表日志一定要丢弃。

快照引用遵守[契约资产第6节](net-the-spire/contract-artifacts.md#6-暂不放宽的边界)，不能引用临时请求账本；仍被保留 episode/数据集使用的快照必须保留且摘要可校验。量化/蒸馏/导出或推理精度改变按 V-16 作为新模型重评，不能复用量化前的学习/资源验收结论。

候选模型通过适用验收后，由维护者授权晋升；发布原子切换完整 ModelBundle，新局开始加载，正在运行的一局继续原包。模型退回上一有效包只影响新局，不是游戏回退；仍需身份兼容，不能以旧包配新规则。
