## 1. 架构评估与决定

保留现有结构：公开实体/字段/关系编码器、共享候选表示、候选概率头及内部V头。增加一个**仅训练及离线检查使用的后果预测头**，学习`(当前公开观察, 实际动作) → 下一公开观察中可核对的字段`。部署仍只运行原编码器和候选评分器。本轮不增加Transformer、在线想象搜索、独立第二个编码器或好奇心奖励。

| 收益 | 代价 / 本轮处理 |
| --- | --- |
| 标签来自实际公开转移，不依赖人工给每种mod效果打分 | 数据仍要覆盖动作及效果；冻结采集分布并报告未覆盖部分，不以目录大小代替学习范围 |
| 复用已有实体、字段、引用和动作表示；预测训练能更新共享参数 | 增加训练头、损失、优化器状态和产物管理；先交最小预测闭环，不同时改整套模型框架 |
| 训练头可从策略部署包中去除 | 采集、预训练及迁移评价都有成本；与从头策略学习比较时单独列总成本，不能称为免费提升 |
| 真实字段标签避免仅预测可塌缩的潜在向量 | 大量字段不变会掩盖无效预测；必须比较保持原值、忽略动作两个基线并报告变化字段 |
| 同一泛化实现可以按不同固定Gym分别训练 | 当前内容embedding由catalog绑定，新mod不保证零样本迁移；作者Gym另建字典/模型，严格区分复用算法与复用权重 |

**预测正确不等于选得好。** 不设任务偏好的纯自监督阶段只产出表示和预测器，不产出经过训练的获胜策略。共用参数变化可能使原概率输出变化，但这不是概率头得到策略标签。公开观察也不保证Markov充分；随机或隐藏因素导致的不可预测部分不能靠恢复RNG补齐。

因此先预训练、再做共同目标下的策略对照，暂不联合优化预测/PPO损失。这样能分清新增模块的收益与成本，避免辅助梯度负迁移、系数选择与探索奖励同时变化。迁移对照采用最少领域假设的终局胜负目标，明确属于强化学习；若将来彻底放弃胜负目标，交付范围应改为预测/探索系统，不能沿用“获胜策略”验收。

方法依据：[UNREAL论文](https://arxiv.org/abs/1611.05397)研究共享表示和辅助任务；[自监督好奇心论文](https://proceedings.mlr.press/v70/pathak17a/pathak17a.pdf)讨论动作后果预测及随机性。本项目采用训练头与共享表示的思路，不复刻其算法，也不由论文推断本项目必然改善。

## 4. D4-A：公开转移数据，先验证标签

复用EpisodeRecord/collector/client/encoder，不新增并行轨迹格式。只接受记录中真实存在的`confirmed`动作和按`next_observation_id`找到的下一快照；同局、同身份、请求不重计。最后一条有真实terminal快照可以用，没有后快照的截断/未知/故障动作不可补造标签。终局的预测样本可以编码后快照，但不能为其伪造候选概率。

首版目标仅为**同一公开实体、同一声明字段在前后都已知的number/boolean值**。逐字段对齐使用持久句柄与字段声明ID；ID用于连接，不进入输入。新增、消失、未知、未提供、类别、引用和关系目标本轮只计覆盖/排除原因，不能填0或推断隐藏卡牌。不承诺完整下一观察生成。number中若有声明为身份/时钟/协议流水号的控制元数据，排除并列明；合法的游戏数值和公开位置不能因难预测而删除。

默认Gym不加Host开关。均匀合法策略采集96局，每局最多128动作，环境seed按train61000～61063、validation62000～62015、final63000～63015；执行器seed=环境seed+1000000。每个split按整局隔离。旧D1/D2数据可用于小型开发冒烟，不能混入正式D4保留集；D2规则动作不用于训练。训练不读胜负、奖励、卡牌效果文字或规则动作。

数值目标为下一值减当前值。每个字段的缩放仅用train已知数值差计算`max(1, RMS(delta))`；验证/最终固定使用此统计。布尔目标是下一布尔值。报告每字段、每动作类型、变化/不变目标数量及比例；至少train有100个、validation和final各有30个数值变化目标，至少两个真实动作类型有变化目标。门槛只确认最小信号量，不证明数据充分。不足时输出缺口并停止该Gym实验，不加采样、不改标签定义。

验收：真实录制后离线重读/重编码；错接下一快照、未知后状态、句柄换名、重复请求等必要反例能发现问题；一致换名不改变标签数值或预测输入。不要为每个平凡辅助函数写镜像测试。

## 5. D4-B：共享表示与训练头

复用`SnapshotEncoder`及`CandidateScorer`返回的`candidate_vectors`。每个目标输入拼接：当前global向量、目标实体向量、已执行候选向量、字段embedding、动作引用角色向量、当前已知数值/布尔通道。动作引用角色向量由所选候选中“引用了当前目标实体”的具名字段embedding取均值构成，无匹配为0，使用前快照公开引用关系；不把句柄数值送入网络。它避免同值同类型实体只凭聚合向量无法区分是否被所选动作引用。只取合法实际候选；不读取下一快照特征。一个共享16维tanh层加数值/布尔两个输出通道（带bias；当前值用number/boolean两个通道，其他类型置0；默认维度额外参数应为1362，须实际核对），数值输出归一化delta，布尔输出logit。不按卡牌/敌人/Power分配专用预测网络。

训练参数包括`emb/`、`entity/`、`field/`、`relation/`、`global/`及`candidate/W_in,b_in`，外加预测头。排除`candidate/W_global`、`candidate/v`和`value/`；按显式参数集合更新，不能因共享ParameterSet顺带更新未授权头。报告实际参数组及梯度，非每批所有组都必须非零；未覆盖的embedding可以不变。

数值使用归一化delta的MSE，布尔使用稳定BCE；先在各字段内平均，再在有样本的字段间平均，再对有样本的数值/布尔类型等权平均。mini-batch按32个真实转移抽样，不拆散数据split；缺某类目标就不参与该批类型平均。Adam learning_rate=0.001，beta1=0.9，beta2=0.999，epsilon=1e-8，max_grad_norm=1；128次更新，模型/采样seed=20261004，默认现有维度/float64。最多第0/32/64/96/128次用validation检查，选validation最低共同loss的checkpoint；final只评一次。

已核验的静态ModelInput和目标可以按原记录/Manifest/EncodingConfig摘要缓存，避免每次更新重复协议审计；共享表示必须用当前权重重新前向，不缓存旧embedding或跳过首次校验。

同数据、同初始化、同预算再训练一个**动作盲预测器**：不接执行候选，候选向量及动作引用角色向量都为0，对应动作参数不更新，其余结构/训练口径相同。第三基线为保持原值：number delta=0、boolean next=current。总误差、逐字段误差、变化子集误差及动作盲差值同时报告；布尔保持原值报告准确率/Brier，不用无穷BCE当比较优势。整体loss下降但变化数值误差不优于保持原值，明确结论“未证明后果学习有效”。

Checkpoint包含策略共享权重、预测头权重、优化器/RNG/游标、目标统计和数据/配置摘要；正常阶段边界可恢复，复用已有资源/故障账目，不承诺任意文件写入瞬间的崩溃事务。输出单独的预测训练产物；策略导出仍兼容`small-policy-bundle@1`，不把预测头参数塞入旧策略格式。所有更新后刷新模型权重摘要/身份，保存及重载交叉验证；不能沿用过期model_id。策略包标记`self-supervised-pretrained / policy-untrained`，禁止误标PPO策略。

验收：梯度确实进入共享表示及所选动作表示；策略最终头/V不变；恢复后的下一更新与连续训练一致；删除预测训练产物后策略包仍可加载、合法概率归一、候选换序与句柄换名不影响语义得分。报告策略参数/权重字节、预测头额外参数、训练RSS/耗时和推理延迟；不据权重字节声明进程内存。

## 6. D4-C：表示是否帮助策略学习

只用default Gym。B的正式预测产物和摘要冻结后，跑三对策略训练：replicate r=0/1/2，初始化seed=20261004+r。每对scratch从该seed初始化；pretrained从该seed初始化并只复制B列出的共享参数，概率最终头及V头与对应scratch初始值完全相同，优化器清空。r=0的共享初值与预训练来源相同；r=1/2衡量不同最终头初始化的稳定性，不算三次独立预训练。

两臂都用同一个新`terminal-only@1`工程任务目标：中途奖励0，真实win+1/loss−1，gamma=1；不读玩家/敌人HP，不加进度/好奇心/步数奖励。截断按显式非终局处理和已有bootstrap约定，故障不作输；报告终局覆盖率及失败样本，不据幸存完整配对掩盖缺失。这是用于验证表示的RL对照，不是整个项目变成纯无监督，也不承诺终局信号足够学会获胜。

每臂4轮×4局，最多2048训练动作；其余PPO完全复用D1（lr=.002、clip=.2、epochs=2、value_coef=.5、entropy_coef=0、max_grad_norm=1及Adam参数）。训练环境seed=64000+100*r+4*k+j（k从0起）；同对两臂相同。执行器seed=环境seed+1000000，训练RNG seed=20261004+r。不选最优训练轮，固定最后完整轮模型，未完成预算独立标记。

模型冻结后，每臂在seed65000～65015各评价16局；均匀基线与既有规则基线各16局，规则只是参照，不进入采样/更新。合计96训练局、128评价局；按环境seed聚类报告胜率、真实终局±1回报差、缺失配对和区间；三个replicate不是48个独立场景。不能把预训练前后预测误差或EndTurn概率作为胜率提升的替代。无改善也交付完整结论，禁止自动增加epochs、奖励项、容量或保留集尝试次数。

只有三个replicate均有正的配对胜率差，且以环境seed为簇的1000次bootstrap（seed=20261004）平均差95%区间下界>0、无技术故障且资源合规，才标为“本切片有策略收益证据”；否则标记无证据/不确定，不晋升。即使满足也只能候选，不替代真实游戏和完整Run验收。C仍执行一次，即使B预测未达优势，用于检验两种指标是否一致；A标签/身份不成立、B无有效梯度或模型损坏则禁止C。

公平成本分两张表：等PPO预算的表示对照，以及含采集/预训练/动作盲实验的总时间和动作成本。本轮不声称等总预算优于scratch；额外等总成本实验留给负责人决定。
