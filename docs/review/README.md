# review 阅读入口

日常工作从[主清单](tofix/README.md#当前交付)进入；后续架构评估读[base 内容与行为重构目标](../design/mod-the-spire/content-behavior-refactor-goals.md)。当前 DSL 结构见[base 组织说明](../design/mod-the-spire/base-architecture.md)。不需要先读旧交接、旧对比或完整历史索引。

| 要查什么 | 去哪里 | 阅读边界 |
| --- | --- | --- |
| 当前目标、认领、顺序、剩余工作与完整验收合同 | [tofix 主清单](tofix/README.md) | 唯一当前任务表；旧任务详情作为合同追溯 |
| 最近交付的实际修改、来源与验证 | [records 按主题索引](records/README.md) | 带日期的历史证据，不是当前设计或下一步指令 |
| 已有关闭依据的窄缺陷 | `archived/` | 只证明对应关闭范围，不代表整个领域完成 |
| 被替代或已撤销的材料 | [deprecated 说明](deprecated/README.md) | 不作为开发接手、当前架构或验收入口 |
