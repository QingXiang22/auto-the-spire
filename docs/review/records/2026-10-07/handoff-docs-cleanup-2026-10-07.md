## 接手后先做什么

1. 在项目根目录运行 `git status --short`，按[文档总入口](../../../README.md#接手路径)进入主清单的任务索引。
2. 进入本次授权任务的详情，核对主责/会话、修改边界、依赖与已交付部分，再按“接手先做”继续。C 线已有 DS 认领，不因文档重排另开会话或重复实现。
3. 用原完成条件判断本包是否可交付；A 的后续修复自报、负责人旧复核和 B/C 尚缺证据已分别标识。任务状态只更新详情，历史过程写 records/artifacts。

本次文档维护无待续工作，也没有新增生产任务。完成条件为范围/认领保留核对、六项接手自查、doc-check 和 git diff --check；由本次负责人登记维护结论。
