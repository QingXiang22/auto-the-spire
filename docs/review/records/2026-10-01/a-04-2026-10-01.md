## 4. 跨样本误连（本任务头号验收）的覆盖

`collate` 组按台账 §2.3 的三个陷阱各有检查（名称见 `run_checks.py --only collate` 输出）：

| 陷阱 | 检查 |
| --- | --- |
| padding 行的填零索引列不得连到本样本第 0 行 | `collate/padding-rows-are-not-row-zero` |
| 同槽位引用不得跨样本互解 | `collate/cross-sample-same-slot-not-crosslinked` |
| `reference_map` 按样本隔离 | `collate/reference-map-per-sample` |
| `reference_mask` 仅 known entity_ref 为真 | `collate/reference-mask-only-known-entity-ref` |
| 越界索引拒绝 | `collate/out-of-range-index-rejected` |
| 混批 Manifest / EncodingConfig 拒绝 | `collate/mixed-manifest-rejected`、`collate/mixed-encoding-config-rejected` |
| 三样本不等长补齐隔离 | `collate/three-samples-varied-lengths` |
| 真行的局部索引在补齐后不变 | `collate/true-rows-keep-local-indices` |

另：`tensorize/permuted-wire-order-rejected` 与 `tensorize/hidden-order-not-encoded` 覆盖 §9 第 10/11 条（隐藏顺序不入编码；非法 wire 顺序被拒而**不是**由校验器替提供方排序），`tensorize/repeat-and-interleaved-are-identical` 覆盖重复/交错编码的确定性。
