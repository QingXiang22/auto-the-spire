## 3. 公共契约变化（其他 agent 需知）

1. **`PrimitiveSignatures` 缺 `expr.scope`**：任何使用 `FrameScopeExpr`（创建实体/作用域的常见写法）的包此前都会以 "unknown primitive" 链接失败。已补。
2. **限定名声明**：`EntityType("other-package:Thing")` 现在表示"声明另一个包的声明"。这是 `Overrides` / `Extends` 唯一可用的表达方式（限定 ID 含包名，按普通名派生无法产生冲突）。声明**种类之间是独立命名空间**：同名 `EntityType` 与 `Action` 不冲突。
3. **动作 guard/候选查询/choices 只能读取"有域"的参数**（有候选查询或有声明 choices）。原因是可用性必须在没有宿主参数时也可判定。B-05 生成的前端若让 guard 读取普通参数，包将无法链接。
4. **`LegalAction` 形状改变**：由 `(Candidates, Choices)` 改为 `(Domains, Bindings)`，`Candidates` 变为便捷属性。`Domains` 给出每个可枚举参数的取值域，`Bindings` 给出当前 guard 成立的参数元组。N-01 设计动作目录时应以 `Domains`/`Bindings` 为准。
5. **每个指令的执行是原子的**：任何指令失败都会回滚它自己的状态写入；消耗随机的指令还会回滚 RNG。执行期故障把会话置为 `Faulted`；**宿主输入拒绝**（guard 不成立、候选不符、角色不符、过期/重复应答）不改变状态、不消耗 RNG、也不会终止会话。
6. **决策绑定状态版本**：`DecisionRequest.StateVersion` 与当前版本不符即 `StaleDecision`；应答在暂停点之后继续，不重放已结算效果。
7. **随机算法与取整档位显式进入身份**：`RandomService(seed, algorithmId, drawProfileId)`，未实现的算法/档位直接拒绝。默认 `xoshiro256ss/splitmix64@1` + `rejection-uniform@1`。**不宣称与原版种子等价**，且 `Engine/` 内没有 `System.Random`（已 grep 确认）。原版有界取整映射需要 B 批带源码证据另行声明。
8. **作用域父类型按作用域类型解析**（原实现按实体类型解析，任何带 `Parent` 的作用域类型都会失败）；父链环检测为 `DependencyCycle`。
9. **compute 资产必须声明 `BackendId` / `SourcePath` / `SourceHash` / `Entry`**，输入输出数量不得超过声明的 `ComputeLimits`；没有安装后端时 `compute` 指令是明确的 `Unsupported` 故障。
10. **`Temp()` 默认类型**由 `Int` 改为 `Any`（绑定槽），算术遇到未绑定槽会报错而不是静默按 0 处理。
11. 数值契约：定点/整数溢出、除零、取整都返回 `EngineFaultException`，不再泄漏 `OverflowException`。

## 5. 未验证与残余风险

1. **仍无正向夹具的 IR 原语**：关系查询/`SamplePick`/`ShuffleCollection` 指令/`Sort`/`Take`/`Skip`/`Aggregate`/`ForEach` 的包级正向行为、`EntityRefList`/`Int`/`Bool`/`Confirm`/`Enum`/`Participant` 决策种类、多输出 compute、作用域类型带父级的实际创建，只有定义检查或部分覆盖，**没有端到端行为证据**。空聚合当前定义为返回 0。
2. **未做性能与规模测量**：状态哈希与观察是 O(状态)；每条消耗随机的指令会复制全部随机流快照。未测大状态/长对局。
3. **已知建模缺口**：非可选 `Ref` 字段在实例创建时按 `None` 初始化（默认值不重新校验）；`StateStore` 只对 Persistent 字段进入哈希与快照，ExecutionOnly 字段不校验用途（目前无包使用）。
4. **Linker 残留**：`Linker._declaringPackage` 是只写状态，未清理（避免无谓改动）。
5. **旧入口不可度量**：`Core.TheSpire.Tests` 仍在首个失败中止，覆盖数字不可用；本批证据完全不依赖它。
