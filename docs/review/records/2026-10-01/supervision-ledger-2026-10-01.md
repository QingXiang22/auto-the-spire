### 2.3 A-04 复核配方（权威＝`encoder-design.md` §5.1，L149-173）

- **B 轴**：*每个样本独立补齐*（per-sample padding），"引用索引属于同一 B 样本，不引入可学习的 `sample_id`" → **跨样本误连正是本任务的头号缺陷**。
- **三个必须被反例钉住的陷阱**：① **padding 行**必须 `mask=false`，且其**填零的索引列不得解析成本样本第 0 行实体**（索引 0 + 忽略 mask = 经典跨行/跨样本误连）；② `reference_mask` **仅在 known entity_ref 时为 true**，unknown/unavailable 不得置真；③ 索引列（owner_entity/owner_candidate/…）的解引用必须**限定在同一 B 样本的行范围内**，越界即拒绝。
- **块与列**（8 块，逐块核对列名齐全）：`entities[B,Emax]`(kind_id/content_id/content_state/content_mask/entity_mask)、`fields`(owner_entity/field_id/value_type/knowledge_state/值通道/field_mask)、`relations`(type_id/source/target/可选 position/position_mask/relation_mask)、`pile_positions`(pile_entity/card_entity/absolute_position/position_record_mask)、`sequences`(sequence_type/owner/element/ordinal/sequence_record_mask)、`groups`(group_type/owner/member/multiplicity/group_record_mask)、`candidates`(action_type/candidate_mask；句柄在侧信息)、`candidate_fields`(owner_candidate/field_id/value_type/knowledge_state/值通道/field_mask)。
- **dtype**：类型/状态/行索引/计数/位置 = `int64`；mask = `bool`；number 通道 = `float64`；**不得把 int64 类别/位置当浮点特征**。
- **固定枚举序数**：`value_type` pad=0/number=1/boolean=2/category=3/entity_ref=4；`knowledge_state` pad=0/known=1/unknown=2/unavailable=3；`content_state` 同族 pad=0/…（以文档为准）。
- **值通道**：`number_value/boolean_value/category_id/reference_entity/reference_mask`；未启用通道**填零**；category 与 entity_ref **不转连续浮点**。
- **数值**：wire 十进制字符串**先精确解析**，再用 Manifest 固定变换转 float64；检查有限值与 absolute/relative tolerance，超限报 **`numeric_precision_loss`**。
- **顺序/位置语义**：`ObservedSequence.ordinal` 从 0 起且同序列连续；`KnownCardPosition.absolute_position` 从 0 起、**允许空洞**；`Relation.position` 仅在该关系声明含此语义时有效（单位/范围/起点由 Manifest 该声明给出）。

**M1 定义**（开工清单 §1）：同一个已验证的受控 STS 战斗切片可从通用 core 经 base-spire/net 被 Python 客户端运行，AI 能正确编码当前公开快照、输出随机合法候选概率并记录实际转移。**随机策略只证明管道，不证明学习效果**；必须走新通用运行时，只包装旧 `CombatEnvironment` 不算完成。

**必查的端到端链路**（清单 §8 六条，逐条给证据）
1. `describe`/`get_catalog` → 启动新局 → `observe` → 校验/编码 → 概率返回 → 采样/选择 → `step` → 当前快照；运行至确认终局或明确测试截断。
2. Headbutt 中途选择正确续接；**其结算后的第一份快照可直接得到已知位置，不需要历史**；重复卡牌实例与两个目标引用准确。
3. 改变隐藏顺序**不改变**公开输入；改变玩家已知事实**不被**编码合并；投影/编码/规则检查各有独立判定依据。
4. 候选重排与句柄换名后，同概率/执行 RNG 按规范键选择相同动作语义；概率只覆盖真实候选，内部 padding 为 0。
5. 保存完整公开轨迹、实际行为概率、`request_id`、规则/模型/字典身份、终止/截断/故障；无神经网络时**模型身份显式为随机基线**，不得称训练模型。
6. 失败路径按规范处理：重发/过期/断开/超限/终止无候选；**不得假装游戏失败或自动重试真实结果**。
