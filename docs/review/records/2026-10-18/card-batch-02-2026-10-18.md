# 全员攻击模板与四张新牌交付记录

日期：2026-10-18。任务：**CORE-AUTHOR-05／DSL-CARD-BATCH-02**；当前认领、状态与恢复顺序只维护在[主清单](../../tofix/README.md#当前交付)。本记录对应[卡牌效果规格](../../../design/mod-the-spire/card-effects/spec.md)的后续包小节，是实施与自查记录，不是独立评审，也没有独立原版对拍。

## 交付与范围

新增 `AttackAllEnemiesEffect`：监听 `CardPlayed`，对每个 `Hp > 0` 的开发目标逐段调用 `DamageEnemyPowered`，因此每个目标分别扣格挡并各自应用 Strength／Vulnerable 修正。其余效果全部复用既有模板（`BlockEffect`、`LoseHpEffect`、`ApplyEnemyPowerEffect`、`ApplyAllEnemiesPowerEffect`）。

迁移四张牌：

| 内容 | 源 | 行为 |
| --- | --- | --- |
| Taunt | `Taunt.cs` | 1 费有目标技能：7／8 格挡后对目标 Vulnerable 1／2 |
| Tremble | `Tremble.cs` | 1 费有目标技能、消耗：Vulnerable 3／4 |
| Thunderclap | `Thunderclap.cs` | 1 费全体攻击：每个敌人 4／7 伤害，之后每个敌人 Vulnerable 1 |
| Blood Wall | `BloodWall.cs` | 2 费：先失去 2 生命，再获得 16／20 格挡 |

包版本升到 `0.5.0-dsl.10`，卡牌定义 20 张（Ironclad 19＋无色 Shockwave）。有目标技能仍由公开动作 `PlayAttackFromHand` 打出；该动作的实际含义是“打出 `Targeted=true` 的牌”，命名债登记在此，后续重命名为 `PlayTargetedCardFromHand` 时要同步检查与 net 轨迹。

## 来源依据

四张牌的源 hash 均由已安装 skill 的定位助手从安装路径核对为 `source_hash_status: matches`，资格 `singleplayer`：

| 内容 | 源 | hash 前缀 |
| --- | --- | --- |
| Taunt | `Taunt.cs` | `8a0bb5f3…1858d4d4` |
| Tremble | `Tremble.cs` | `87308806…b71bc9cd` |
| Thunderclap | `Thunderclap.cs` | `e37f9e89…99620e81` |
| Blood Wall | `BloodWall.cs` | `2ce56cad…83b7165e` |

Thunderclap 的伤害在源里通过 `TargetingAllOpponents` 一次性施加，本包按目标逐个结算；对单目标结果相同，多目标时每个目标独立扣格挡与修正，符合逐目标的伤害修正语义。

## 实际验证

Windows／PowerShell，.NET SDK 9.0.306；Debug 配置。

| 命令 | 实际结果 |
| --- | --- |
| `dotnet build AutoTheSpire.sln -v minimal` | 通过，0 警告／0 错误 |
| `dotnet run --project tools/base-spire-dev -- validate` | 退出 0；包 `0.5.0-dsl.10`；card 目录 578 源／20 个 DSL definition |
| `dotnet run --project tools/base-spire-dev -- check --report .artifacts/base-dsl/behavior` | 72 项全部通过 |
| `python -X utf8 tools/ci/check_relic_coverage.py .artifacts/base-dsl/behavior/package-behavior.json` | 退出 0：8 件遗物行为见证；源 297；未实现 288；`independent_verified=false` |
| `dotnet run --project net-the-spire/Net.TheSpire.Tests` | 359 项通过／0 失败，含新增 CP44 Thunderclap 真实 stdio 轨迹 |

新增判别覆盖：Thunderclap 先对两个目标各造成 4 点（目标 40→36）、再各施加 1 层 Vulnerable，第二次打出时升级版 7 点按 1.5 倍向下取整为 10（36→26）；Taunt 同一次出牌先得 7 格挡再施加 Vulnerable，升级后 8 格挡与 2 层；Tremble 施加 3／4 层并进入消耗堆；Blood Wall 先失去 2 生命（80→78，不受格挡影响）再获得 16 格挡，升级后 20 格挡。真实 stdio 轨迹提交 `Thunderclap.AddToHand` 与 `PlayCardFromHand`，观察公开目标 40→36、能量 3→2 与 `Power.Stacks` 1。

## 未验证与未支持

- 未运行独立原版对拍、完整 Engine 套件（留给 Actions）、正常 Run、完整游戏矩阵与性能套件；`independent_verified` 保持 false。
- 未实现：敌方回合与敌方攻击（Weak 仍无可观察效果）、原版目标选择与公开决策应答、卡牌获得途径、死亡与胜负、敌方格挡修正参与者。

- 四张牌的普通／升级数值按源核对，但动画、音效与卡面文案不迁移。
