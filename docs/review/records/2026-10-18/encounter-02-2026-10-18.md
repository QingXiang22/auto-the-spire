## 交付与范围

新增开发态候选池 `EnemyPoolEntry`／`EnemyPool`（内部实体，不进入公开投影），以及编队模板 `RubyRaidersFormation`：

1. 建池：按源池顺序放入 AxeRubyRaider（20 HP）、AssassinRubyRaider（18）、BruteRubyRaider（30）、CrossbowRubyRaider（18）、TrackerRubyRaider（21）。
2. 三次抽取：每次 `samplePick(stream = "base-spire:development-encounter", candidates = collection(EnemyPool))`，抽出后立刻移出集合再刷怪，因此三只**互不相同**（对应源 `uniqueChoiceGroup = distinct-ruby-raiders`）。
3. 清池：销毁剩余候选，避免跨遭遇泄漏。

内容 `base-spire:ruby-raiders-normal`（源 `RubyRaidersNormal.cs`：Monster 房、三个槽位、从五种 Ruby Raider 随机选且互不相同）。包版本升到 `0.5.0-dsl.19`，遭遇定义 2/88。

**已知偏差**：源从 run RNG 抽取，本包用 Engine 默认随机 profile 的命名流 `base-spire:development-encounter`，因此**不重现源的具体抽取序列**；候选顺序与“不放回”语义保留。

不迁移：遭遇池与队列、房间入口、权重与弱/普通资格、开场动作、其余 86 个遭遇、Run／奖励。

## 来源依据

`sts2/src/Core/Models/Encounters/RubyRaidersNormal.cs` 与 `encounters/source.json` 中该遭遇的 `enemySlots`：三个槽位都从 `axe-ruby-raider／assassin-ruby-raider／brute-ruby-raider／crossbow-ruby-raider／tracker-ruby-raider` 中 `chooseRandomly`，并共享 `uniqueChoiceGroup = base-spire:distinct-ruby-raiders`。源 hash 由已安装 skill 的定位助手从安装路径核对为 `source_hash_status: matches`，资格 `singleplayer`。候选的 HP 取各自敌人的 Ascension 0 最小值。
