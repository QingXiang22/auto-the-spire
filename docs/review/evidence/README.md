# 历史证据归档

本目录保全2026-10-15清理前，被已提交文档直接引用的本地证据及其Markdown链接目标，另含公开商店默认重放输入。压缩包不是新的运行结果，也不改变原报告的验收范围。

归档清单：[逐文件路径、长度及SHA256](linked-evidence-20261015.json)。数据包：[原始证据ZIP](linked-evidence-20261015.zip)。目录链接只保留目录本身和被单独引用的文件，不承诺收录目录内所有临时产物。

从干净检出恢复这些历史链接，在仓库根目录运行：

```powershell
python tools/doc-check/restore_evidence.py
```

仅校验压缩包及现有同名文件时加 `--check`。脚本在写入前核对整个包的摘要和成员清单；同名文件内容不同时拒绝覆盖。恢复位置仍为原来的 `.audit`、`.artifacts`、`artifacts`或提取报告目录，这些位置按用途忽略。其余本地原始产物未删除；清理前完整备份另存于仓库外。

原版 `sts2/` 源码、外部参考克隆和历史二进制依赖不是本归档的替代对象。完整文档检查仍需提供被引用的同版本本地原版源码；严格对拍参考的恢复见[参考依赖说明](../../../reference/README.md)。不能用恢复旧证据代替当前构建、规则检查或新的双侧运行。
